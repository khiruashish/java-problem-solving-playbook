    Segment tree¶

    Expert Divide & conquer Range queries

    Problem¶

    An array changes over time. Support update(i, value) and the range queries sum(l, r) and min(l, r), all in O(log n).

    Thinking process¶

    1. Plain array: update O(1), query O(n). Prefix sums: query O(1), update O(n). Interleaved operations make both too slow.
    2. Segment tree: a binary tree where each node stores the answer (sum, min, …) for a range. The root covers [0, n−1], and each node's two children cover its two halves. It's stored in an array: the children of node i are 2i and 2i+1, and 4n slots are always enough.

    3. Query(l, r) at a node covering [lo, hi]:

      • no overlap: return the neutral value (0 for a sum, +∞ for a min);
      • total overlap: return the stored value;
      • partial overlap: ask both children and combine.

      Any range splits into O(log n) fully covered nodes. 4. Update(i): walk from the root to the leaf, then recompute every ancestor on the way back up (pull). O(log n). 5. It works for any associative operation: sum, min, max, gcd, XOR, matrix product.

    Tree for [2, 1, 5, 3] (sum / min)¶

                  [0,3] 11/1
             /          \
      [0,1] 3/1        [2,3] 8/3
       /     \          /     \
    [0] 2  [1] 1     [2] 5  [3] 3

    Code¶

    package com.playbook.advanced;

/**
 * Segment tree over an int array: point update and range SUM / range MIN queries, each O(log n).
 * Node i covers a range; its children 2i and 2i+1 cover the two halves. Size 4n is always enough.
 */
public final class SegmentTree {
    private final int n;
    private final long[] sum;
    private final int[] min;

    public SegmentTree(int[] a) {
        n = a.length;
        sum = new long[4 * Math.max(1, n)];
        min = new int[4 * Math.max(1, n)];
        if (n > 0) build(a, 1, 0, n - 1);
    }

    private void build(int[] a, int node, int lo, int hi) {
        if (lo == hi) {
            sum[node] = min[node] = a[lo];
            return;
        }
        int mid = (lo + hi) >>> 1;
        build(a, 2 * node, lo, mid);
        build(a, 2 * node + 1, mid + 1, hi);
        pull(node);
    }

    private void pull(int node) {                            // recompute a parent from its children
        sum[node] = sum[2 * node] + sum[2 * node + 1];
        min[node] = Math.min(min[2 * node], min[2 * node + 1]);
    }

    /** a[index] = value. Walk root → leaf, then fix every ancestor on the way back. O(log n). */
    public void update(int index, int value) {
        update(1, 0, n - 1, index, value);
    }

    private void update(int node, int lo, int hi, int idx, int value) {
        if (lo == hi) {
            sum[node] = min[node] = value;
            return;
        }
        int mid = (lo + hi) >>> 1;
        if (idx <= mid) update(2 * node, lo, mid, idx, value);
        else update(2 * node + 1, mid + 1, hi, idx, value);
        pull(node);
    }

    /** Sum of a[l..r] inclusive. A query range is covered by O(log n) whole nodes. */
    public long sum(int l, int r) {
        return sum(1, 0, n - 1, l, r);
    }

    private long sum(int node, int lo, int hi, int l, int r) {
        if (r < lo || hi < l) return 0;                      // no overlap
        if (l <= lo && hi <= r) return sum[node];            // total overlap: use the stored answer
        int mid = (lo + hi) >>> 1;                           // partial overlap: ask both children
        return sum(2 * node, lo, mid, l, r) + sum(2 * node + 1, mid + 1, hi, l, r);
    }

    /** Minimum of a[l..r] inclusive. */
    public int min(int l, int r) {
        return min(1, 0, n - 1, l, r);
    }

    private int min(int node, int lo, int hi, int l, int r) {
        if (r < lo || hi < l) return Integer.MAX_VALUE;
        if (l <= lo && hi <= r) return min[node];
        int mid = (lo + hi) >>> 1;
        return Math.min(min(2 * node, lo, mid, l, r), min(2 * node + 1, mid + 1, hi, l, r));
    }
}

    Complexity¶

    Build O(n) · update O(log n) · query O(log n) · space O(4n).

    Beyond this page¶

    Lazy propagation handles range updates ("add 5 to a[l..r]") in O(log n), by deferring work to the children until it's needed. That's the next step after mastering this version.

    Testing note¶

    100 random arrays × 200 interleaved updates and queries, checked against direct loops.
