BFS from 0: visit by distance
  1. Start at 0 (distance 0). Mark nodes as seen when they're enqueued, so nothing is queued twice.
  2. Poll 0 (distance 0) and visit it. Enqueue unseen neighbours 1, 2 at distance 1.
  3. Poll 1 (distance 1) and visit it. Enqueue unseen neighbours 3 at distance 2.
  4. Poll 2 (distance 1) and visit it. No unseen neighbours.
  5. Poll 3 (distance 2) and visit it. Enqueue unseen neighbours 4 at distance 3.
  6. Poll 4 (distance 3) and visit it. No unseen neighbours.
  7. BFS order 0 1 2 3 4, by distance. Node 5 was never reached: it's a second component. O(V + E).
