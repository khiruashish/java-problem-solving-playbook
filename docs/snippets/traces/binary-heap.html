Min-heap: push 5, 3, 8, 1, then pop
  1. An empty min-heap: every parent ≤ its children, so the minimum is always at index 0.
  2. push(5): append at index 0.
  3. push(3): append at index 1.
  4. 3 < its parent 5: swap upwards.
  5. push(8): append at index 2.
  6. push(1): append at index 3.
  7. 1 < its parent 5: swap upwards.
  8. 1 < its parent 3: swap upwards.
  9. pop() returns 1. Move the last element (5) to the root, then sift it down.
  10. Swap with the smaller child (3).
  11. The heap property holds again. push and pop are O(log n): one path from leaf to root.
