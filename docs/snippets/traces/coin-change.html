Fewest coins for 11 using [1, 2, 5], bottom-up
  1. dp[0] = 0 (no coins for amount 0). Everything else starts at ∞ (amount + 1, which no real answer can reach).
  2. a = 1: try every coin as the last one: dp[0]+1 = 1. Best is coin 1 → dp[1] = 1.
  3. a = 2: try every coin as the last one: dp[1]+1 = 2, dp[0]+1 = 1. Best is coin 2 → dp[2] = 1.
  4. a = 3: try every coin as the last one: dp[2]+1 = 2, dp[1]+1 = 2. Best is coin 1 → dp[3] = 2.
  5. a = 4: try every coin as the last one: dp[3]+1 = 3, dp[2]+1 = 2. Best is coin 2 → dp[4] = 2.
  6. a = 5: try every coin as the last one: dp[4]+1 = 3, dp[3]+1 = 3, dp[0]+1 = 1. Best is coin 5 → dp[5] = 1.
  7. a = 6: try every coin as the last one: dp[5]+1 = 2, dp[4]+1 = 3, dp[1]+1 = 2. Best is coin 1 → dp[6] = 2.
  8. a = 7: try every coin as the last one: dp[6]+1 = 3, dp[5]+1 = 2, dp[2]+1 = 2. Best is coin 2 → dp[7] = 2.
  9. a = 8: try every coin as the last one: dp[7]+1 = 3, dp[6]+1 = 3, dp[3]+1 = 3. Best is coin 1 → dp[8] = 3.
  10. a = 9: try every coin as the last one: dp[8]+1 = 4, dp[7]+1 = 3, dp[4]+1 = 3. Best is coin 2 → dp[9] = 3.
  11. a = 10: try every coin as the last one: dp[9]+1 = 4, dp[8]+1 = 4, dp[5]+1 = 2. Best is coin 5 → dp[10] = 2.
  12. a = 11: try every coin as the last one: dp[10]+1 = 3, dp[9]+1 = 4, dp[6]+1 = 3. Best is coin 1 → dp[11] = 3.
  13. dp[11] = 3 (5 + 5 + 1). O(amount × coins) time, O(amount) space.
