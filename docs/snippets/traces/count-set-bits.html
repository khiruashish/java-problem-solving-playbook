Brian Kernighan: count the 1 bits of 52
  1. n = 52 = 00110100. n − 1 flips the lowest 1 and every 0 below it, so n & (n − 1) erases exactly that one bit.
  2. Clear bit 2: n = 48 = 00110000. count = 1.
  3. Clear bit 4: n = 32 = 00100000. count = 2.
  4. Clear bit 5: n = 0 = 00000000. count = 3.
  5. n is 0 after 3 rounds: one loop per set bit, not per bit position.
