Dijkstra from 0 with a min-heap
  1. Every distance starts at ∞ except the source. The heap always yields the closest unfinished node.
  2. Pop (0, 0): 0 is final at distance 0. Relax its edges: 1 → 4, 2 → 1.
  3. Pop (1, 2): 2 is final at distance 1. Relax its edges: 1 → 3, 3 → 6.
  4. Pop (3, 1): 1 is final at distance 3. Relax its edges: 3 → 4.
  5. Pop (4, 1): stale, because dist[1] is already 3. Skip it (lazy deletion).
  6. Pop (4, 3): 3 is final at distance 4. No edge improves anything.
  7. Pop (6, 3): stale, because dist[3] is already 4. Skip it (lazy deletion).
  8. Distances [0, 3, 1, 4]. The cheapest way to 1 is 0 → 2 → 1 (cost 3), not the direct edge (4). O((V + E) log V); weights must be non-negative.
