  2. memo(4): not cached, so compute memo(3) + memo(2).
  3. memo(3): not cached, so compute memo(2) + memo(1).
  4. memo(2): not cached, so compute memo(1) + memo(0).
  5. memo(1): base case, return 1.
  6. memo(0): base case, return 0.
  7. memo(2) = 1. Store it, so any later memo(2) is free.
  8. memo(1): base case, return 1.
  9. memo(3) = 2. Store it, so any later memo(3) is free.
  10. memo(2): cache hit, return 1 without recursing. This is the whole speed-up.
  11. memo(4) = 3. Store it, so any later memo(4) is free.
  12. memo(3): cache hit, return 2 without recursing. This is the whole speed-up.
