Jump game II: minimum jumps as an implicit BFS
  1. [start, currentEnd] = indexes reachable with exactly jumps jumps. Scan the level, remember the furthest reach of any of them.
  2. i = 0 reaches 2. Level finished: jump #1. The next level is indexes 1..2.
  3. i = 1: could reach 4; furthest = 4.
  4. i = 2 reaches 3. Level finished: jump #2. The next level is indexes 3..4.
  5. i = 3: could reach 4; furthest = 4.
  6. The last index is in the current level: 2 jumps (0 → 1 → 4). Greedy, O(n), no DP table.
