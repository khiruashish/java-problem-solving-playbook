Level-order traversal with a queue
  1. Start with the root in the queue.
  2. Snapshot size = 1: exactly the nodes of this level are in the queue.
  3. Polled [3], enqueued their children. Level done: [3].
  4. Snapshot size = 2: exactly the nodes of this level are in the queue.
  5. Polled [9, 20], enqueued their children. Level done: [9, 20].
  6. Snapshot size = 2: exactly the nodes of this level are in the queue.
  7. Polled [15, 7], enqueued their children. Level done: [15, 7].
  8. Queue empty: [[3], [9, 20], [15, 7]]. O(n) time, O(width) space.
