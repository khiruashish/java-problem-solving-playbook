Floyd's tortoise and hare on a list whose tail loops back to node 3
  1. Both pointers start at the head. slow moves 1 step, fast moves 2.
  2. slow → node 2, fast → node 3. Once both are inside the loop, fast gains one step per round.
  3. slow → node 3, fast → node 5. Once both are inside the loop, fast gains one step per round.
  4. slow → node 4, fast → node 7. Once both are inside the loop, fast gains one step per round.
  5. slow → node 5, fast → node 4. Once both are inside the loop, fast gains one step per round.
  6. slow → node 6, fast → node 6. They meet: inside a loop the faster runner must land on the slower one, because the gap shrinks by exactly 1 each round.
  7. Phase 2: put p at the head and keep slow at the meeting point (node 6). Both now move 1 step at a time.
  8. p → node 2, slow → node 7.
  9. p → node 3, slow → node 3. Same node!
  10. They meet exactly at the start of the cycle, node 3: the distance from the head equals the distance from the meeting point, modulo the loop length. O(n) time, O(1) space.
