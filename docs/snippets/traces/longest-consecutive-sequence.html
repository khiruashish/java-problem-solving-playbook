Longest consecutive sequence with a HashSet
  1. Put everything in a set for O(1) lookups. Only count from the start of a run, so each number is walked at most once overall.
  2. 100 starts a run: 100, length 1. best = 1.
  3. 4: 3 is in the set, so 4 isn't a start. Skip, its run gets counted from its start.
  4. 200 starts a run: 200, length 1. best = 1.
  5. 1 starts a run: 1 → 2 → 3 → 4, length 4. best = 4.
  6. 3: 2 is in the set, so 3 isn't a start. Skip, its run gets counted from its start.
  7. 2: 1 is in the set, so 2 isn't a start. Skip, its run gets counted from its start.
  8. Answer 4 (1, 2, 3, 4). Each element is touched O(1) times: O(n) without sorting. (Java iterates the set in its own order; the result is the same.)
