Longest substring without repeating characters: "abba"
  1. Window [left, right] holds distinct characters. lastSeen stores index + 1, so 0 means "never seen".
  2. right = 0: a not seen before; left stays 0. Window = "a", best = 1.
  3. right = 1: b not seen before; left stays 0. Window = "ab", best = 2.
  4. right = 2: b was last at index 1, inside the window: jump left to 2. Window = "b", best = 2.
  5. right = 3: a was last at index 0, but that is before left (2). max(left, 1) keeps left at 2. Without max, left would move backwards: the classic bug. Window = "ba", best = 2.
  6. Done: the longest window had length 2 ("ab" or "ba"). Each character is visited once: O(n).
