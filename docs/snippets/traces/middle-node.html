Middle of 1 → 2 → 3 → 4 → 5 → 6 with slow and fast
  1. slow moves 1 node per step, fast moves 2. When fast runs off the end, slow is halfway.
  2. slow → node 2, fast → node 3.
  3. slow → node 3, fast → node 5.
  4. slow → node 4, fast → null (fell off the end).
  5. fast is null: slow is at node 4, the second middle of an even-length list. One pass, O(1) space.
