Move zeros: read and write pointers
  1. Everything before write is a finished non-zero, in order.
  2. a[0] is 0: skip it. write stays at 0.
  3. a[read] = 1 is non-zero: swap it to write (0) and advance write.
  4. a[2] is 0: skip it. write stays at 1.
  5. a[read] = 3 is non-zero: swap it to write (1) and advance write.
  6. a[read] = 12 is non-zero: swap it to write (2) and advance write.
  7. Non-zeros in order, zeros at the end, one pass and minimal writes.
