Number of islands: DFS flood fill
  1. Scan cell by cell. Each '1' that hasn't been visited starts a new island.
  2. (0,0) is unvisited land: island #1. Sink all of it.
  3. Visit (0,0): mark it so it's never counted again, then try its 4 neighbours.
  4. Visit (1,0): mark it so it's never counted again, then try its 4 neighbours.
  5. Visit (1,1): mark it so it's never counted again, then try its 4 neighbours.
  6. Visit (0,1): mark it so it's never counted again, then try its 4 neighbours.
  7. (2,2) is unvisited land: island #2. Sink all of it.
  8. Visit (2,2): mark it so it's never counted again, then try its 4 neighbours.
  9. (3,3) is unvisited land: island #3. Sink all of it.
  10. Visit (3,3): mark it so it's never counted again, then try its 4 neighbours.
  11. Visit (3,4): mark it so it's never counted again, then try its 4 neighbours.
  12. Every cell scanned: 3 islands. Each cell is visited a constant number of times: O(R·C). (The real code sinks a copy, so the caller's grid is untouched.)
