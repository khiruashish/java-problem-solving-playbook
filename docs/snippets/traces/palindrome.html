Two pointers: is "abcba" a palindrome?
  1. Start at both ends and walk inwards.
  2. s[0] = a and s[4] = a match. Move both pointers inwards.
  3. s[1] = b and s[3] = b match. Move both pointers inwards.
  4. left (2) is no longer < right (2): the middle character needs no partner. true after n/2 comparisons, O(1) space.
