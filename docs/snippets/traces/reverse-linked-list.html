Reverse 1 → 2 → 3 → 4 with three pointers
  1. prev = null (nothing reversed yet), curr = head.
  2. Save next = curr.next (node 2) before we overwrite the arrow, or the rest of the list is lost.
  3. Flip: node 1 now points to null.
  4. Advance both: prev = node 1, curr = node 2.
  5. Save next = curr.next (node 3) before we overwrite the arrow, or the rest of the list is lost.
  6. Flip: node 2 now points to node 1.
  7. Advance both: prev = node 2, curr = node 3.
  8. Save next = curr.next (node 4) before we overwrite the arrow, or the rest of the list is lost.
  9. Flip: node 3 now points to node 2.
  10. Advance both: prev = node 3, curr = node 4.
  11. Save next = curr.next (node null) before we overwrite the arrow, or the rest of the list is lost.
  12. Flip: node 4 now points to node 3.
  13. Advance both: prev = node 4, curr = null.
  14. curr is null, so every arrow is flipped. prev (node 4) is the new head: 4 → 3 → 2 → 1. O(n) time, O(1) space.
