Sliding window maximum (k = 3) with a monotonic deque
  1. The deque keeps indexes with decreasing values: the front is always the window's max.
  2. i = 0 (1): push it.
  3. i = 1 (3): 3 dominates 1: they can never be a max again. push it.
  4. i = 2 (-1): push it. Window max = 3.
  5. i = 3 (-3): push it. Window max = 3.
  6. i = 4 (5): index 1 slid out of the window; 5 dominates -3, -1: they can never be a max again. push it. Window max = 5.
  7. i = 5 (3): push it. Window max = 5.
  8. i = 6 (6): 6 dominates 3, 5: they can never be a max again. push it. Window max = 6.
  9. i = 7 (7): 7 dominates 6: they can never be a max again. push it. Window max = 7.
  10. [3, 3, 5, 5, 6, 7]. Every index enters and leaves the deque once: O(n), O(k) space.
