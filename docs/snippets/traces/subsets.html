Subsets of [1, 2, 3] by backtracking
  1. current = [] is a subset: record it. Then try adding each element from index 0 on.
  2. current = [1] is a subset: record it. Then try adding each element from index 1 on.
  3. current = [1,2] is a subset: record it. Then try adding each element from index 2 on.
  4. current = [1,2,3] is a subset: record it. Then try adding each element from index 3 on.
  5. Back in bt(start=1): undo 2, current = [1], and try the next element.
  6. current = [1,3] is a subset: record it. Then try adding each element from index 3 on.
  7. Back in bt(start=0): undo 1, current = [], and try the next element.
  8. current = [2] is a subset: record it. Then try adding each element from index 2 on.
  9. current = [2,3] is a subset: record it. Then try adding each element from index 3 on.
  10. Back in bt(start=0): undo 2, current = [], and try the next element.
  11. current = [3] is a subset: record it. Then try adding each element from index 3 on.
  12. All 2³ = 8 subsets. Adding, recursing and removing (backtracking) reuses one list instead of copying at every step.
