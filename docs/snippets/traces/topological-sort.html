Topological sort with Kahn's algorithm
  1. Count in-degrees. Nodes with none (4, 5) have no prerequisites: ready.
  2. Output 4, and remove its edges.
  3. Output 5, and remove its edges. 2, 0 now has no remaining prerequisites: ready.
  4. Output 2, and remove its edges. 3 now has no remaining prerequisites: ready.
  5. Output 0, and remove its edges.
  6. Output 3, and remove its edges. 1 now has no remaining prerequisites: ready.
  7. Output 1, and remove its edges.
  8. Order 4 5 2 0 3 1: every edge points forward. If a cycle existed, some nodes would never reach in-degree 0 and the order would come out short.
