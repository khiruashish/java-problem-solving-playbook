Trie: insert apple, app, apt; then search
  1. A trie shares prefixes: each node is one character on the way to some words.
  2. insert("apple"): walk/create a → p → p → l → e, bump each prefixCount, and flag the last node as a word end.
  3. insert("app"): walk/create a → p → p, bump each prefixCount, and flag the last node as a word end. Only the new branch was created.
  4. insert("apt"): walk/create a → p → t, bump each prefixCount, and flag the last node as a word end. Only the new branch was created.
  5. search("app"): the walk ends on a node flagged as a word → true.
  6. search("ap"): the walk succeeds but "p" is not a word end → false. startsWith("ap") would be true (3 words pass through). Every operation is O(length).
