Valid parentheses: "{[()]}" with a stack of expected closers
  1. Trick: when we see an opener, push the closer we expect. Then a closer only has to equal the top of the stack.
  2. { opens: push }, the closer we now expect.
  3. [ opens: push ], the closer we now expect.
  4. ( opens: push ), the closer we now expect.
  5. ) closes: pop ), and it matches.
  6. ] closes: pop ], and it matches.
  7. } closes: pop }, and it matches.
  8. End of the string and the stack is empty: valid. With "([)]" the pop at index 2 would give ']' instead of ')', and we'd return false right there.
