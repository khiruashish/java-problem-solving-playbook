Validate BST by passing (low, high) bounds down
  1. Comparing a node only with its children is the classic bug: this tree passes that test. Instead, each node inherits an allowed interval from its ancestors.
  2. 5 must be inside (−∞, +∞): yes.
  3. 1 must be inside (−∞, 5): yes.
  4. 6 must be inside (5, +∞): yes.
  5. 3 must be inside (5, 6): no, 3 ≤ 5. It sits in 5's right subtree but is smaller than 5.
  6. Not a BST. The bounds carry every ancestor's constraint down, so the violation is caught at node 3. O(n) time, O(h) stack.
