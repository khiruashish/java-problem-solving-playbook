    Java Problem-Solving Playbook¶

    From "I don't know where to start" to expert-level answers. Every problem is solved the way a 15-year interviewer expects: think aloud, start with brute force, find the waste, reach the optimal pattern. You get recursive and iterative/normal versions and a Java 8 Streams take where one fits.

    Start with Foundations See the Roadmap

    How every problem page is built¶

    1. Problem + examples + clarifying questions: what to ask before you write a single line.
    2. Thinking process: restate the problem, try brute force, spot the waste, name the pattern.
    3. Approaches, from brute force to optimal: each one with numbered steps and its complexity.
    4. Recursive and Java 8 versions wherever they are natural.
    5. Dry run table: trace the optimal solution by hand.
    6. Code: embedded from the real, compiled and JUnit-tested source in src/main/java.
    7. Edge cases, follow-ups, related problems: what the interviewer asks next.

    Difficulty legend¶

    Badge Meaning
    Easy Single loop or direct API usage
    Medium One well-known pattern (two pointers, hashing, sliding window…)
    Hard A combination of patterns, or an invariant that isn't obvious
    Expert An advanced algorithm (KMP, Manacher, monotonic stack, backtracking with pruning)
